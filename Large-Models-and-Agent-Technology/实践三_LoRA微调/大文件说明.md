# 大文件说明（单文件 >10 MB 不上传 GitHub）

本目录（`Large-Models-and-Agent-Technology/实践三_LoRA微调`）是 **LoRA 微调实践**的完整工作目录。

## 上传规则

> **单文件大于 10 MB 的，一律不上传 GitHub。**
>
> 原因：GitHub 单文件硬上限 100 MB；本目录含 942 MB 模型权重。即使未超硬上限，大文件也会让仓库体积失控（当前 `.git` 已 1.05 GB）。

## 3. 复现方式（被排除的大文件如何获得）

```bash
# 1) 下载基座模型（约 1 GB）
modelscope download --model Qwen/Qwen2.5-0.5B-Instruct --local_dir Qwen2.5-0.5B-Instruct
# 或
huggingface-cli download Qwen/Qwen2.5-0.5B-Instruct --local-dir Qwen2.5-0.5B-Instruct

# 2) 准备数据
python prepare_data.py

# 3) LoRA 训练（产出 qwen0.5b-lora/，其中 adapter_model.safetensors 约 2.1 MB 可上传）
python train.py

# 4) 合并权重（产出 qwen0.5b-lora-merged/，约 1 GB，不上传）
python - <<'PY'
from peft import PeftModel
from transformers import AutoModelForCausalLM, AutoTokenizer
base = "Qwen2.5-0.5B-Instruct"
model = AutoModelForCausalLM.from_pretrained(base, device_map="auto")
model = PeftModel.from_pretrained(model, "qwen0.5b-lora")
model = model.merge_and_unload()
model.save_pretrained("qwen0.5b-lora-merged")
AutoTokenizer.from_pretrained(base).save_pretrained("qwen0.5b-lora-merged")
PY

# 5) 评测
python compare.py
```

## 4. 大文件分发方式（替代 git push）

1. **GitHub Releases**：zip 后作为 Release 附件（单文件 ≤2 GB）
2. **Git LFS**：`git lfs track "*.safetensors"`（免费额度 1 GB）
3. **ModelScope / 网盘**：作为独立模型发布

## 5. ⚠️ 历史提交里已含 942 MB 权重，push 仍会被拒

当前历史 commit `fde81de` 包含 `qwen0.5b-lora-merged/model.safetensors`（942.3 MB）。仅加 `.gitignore` + `git rm --cached` **不能**把历史里的 blob 去掉，push 依然会被 GitHub 拒绝。

清理历史（任选，均为重写历史操作，请先备份）：

```bash
# 方案 A：git-filter-repo（推荐）
pip install git-filter-repo
git filter-repo --path-glob "*实践三_LoRA微调/**/*.safetensors" --invert-paths
git filter-repo --path-glob "*实践三_LoRA微调/**/tokenizer.json" --invert-paths
git remote add origin git@github.com:Nepenthe886/Graduate-course-code.git
git push --force --all

# 方案 B：BFG
java -jar bfg.jar --delete-files "*.safetensors" .
git reflog expire --expire=now --all && git gc --prune=now --aggressive

# 方案 C：新建干净仓库（只复制代码/文档/小文件）
```

> 重写历史后 `.git` 体积可回落到几十 MB 级。
