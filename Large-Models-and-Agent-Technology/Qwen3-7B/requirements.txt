# Qwen3 本地部署依赖（Windows / Python 3.12 / NVIDIA 显卡）
#
# !!! 顺序很重要 !!!
# PyPI 与国内镜像上的 Windows torch 是 **CPU 版**（约 124 MB）。
# 直接 `pip install -r requirements.txt` 会装到 CPU 版，运行时报：
#     AssertionError: Torch not compiled with CUDA enabled
#
# 正确做法（scripts/setup_env.cmd 已自动按此顺序执行）：
#   1) 先装 CUDA 版 torch（主索引必须是 cu128）
#        py -3.12 -m venv .venv
#        .venv\Scripts\python.exe -m pip install torch --index-url https://download.pytorch.org/whl/cu128
#   2) 再装本文件
#        .venv\Scripts\python.exe -m pip install -r requirements.txt -i https://mirrors.ustc.edu.cn/pypi/simple
#   3) 验证（期望：2.x.x+cu128 12.8 True (12, 0)）
#        .venv\Scripts\python.exe -c "import torch;print(torch.__version__,torch.version.cuda,torch.cuda.is_available(),torch.cuda.get_device_capability())"
# ============================================================
